# 5분 탈출: 어두운 공장

Three.js로 만든 3D 3인칭 탈출 게임입니다. 아주 넓고 어두운 공장에서 AI 친구와 함께
졸라맨들을 피해 5분 안에 출구를 찾아야 합니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 안내된 주소(기본 `http://localhost:5173`)로 접속하세요.

프로덕션 빌드:

```bash
npm run build
npm run preview
```

## 조작법

- 방향키 ↑ / ↓ : 전진 / 후진
- 방향키 ← / → : 좌우 회전
- Enter : 약통에 채워진 색을 몸 전체에 채우기 (약통은 비워짐)

## 게임 규칙 요약

- **졸라맨(추격형)**: 시야에 들어오면 쫓아옵니다. 닿으면 즉사.
- **낚시하는 졸라맨**: 제자리에서 낚싯줄을 던집니다. 줄(훅)에 닿으면 즉사.
- **먼지**: 몸에 색이 채워져 있으면(위장 중이어도) 닿는 순간 색을 지워버립니다.
- **색깔 방**: 미로 곳곳의 막다른 방 입구에 무지개색 중 하나의 반투명한 문이 있습니다.
  문에 닿으면 약통에 그 색이 채워집니다.
- **위장**: Enter로 몸 전체를 그 색으로 물들인 뒤, 같은 색의 위장 벽에 붙어 있으면
  졸라맨들이 알아채지 못하고 지나갑니다.
- **AI 친구**: 플레이어를 따라다니며, 위험이 감지되면 스스로 색을 모아 위장하거나
  도망칩니다.
- **출구**: 미로에서 가장 먼 경계 지점에 초록빛 게이트로 표시되어 있습니다.
  5분 안에 도달하면 승리합니다.
