5분 탈출: 잠실 롯데몰

정전된 잠실 롯데몰에 갇혔다. 지하 마켓부터 꼭대기 롯데시네마까지 21개 층이 엘리베이터로 이어져 있고, 졸라맨들이 당신을 쫓는다. 낚시하는 졸라맨의 낚싯대에 걸리면 죽는다. 작은 매장의 투명한 색문에 닿으면 약통에 색이 채워진다. Enter를 누르면 몸 전체가 그 색이 되고, 같은 색 벽에 붙어 있으면 졸라맨들은 당신을 알아채지 못한다. 단, 먼지에 닿으면 색이 지워진다. 바닥에 떨어진 화살·검·마법봉·망치를 주우면 무제한으로 쓸 수 있다. AI 친구와 함께 5분 안에 출구를 찾아 탈출하라.

  • 방향키 ↑↓ : 전진 / 후진
  • 방향키 ←→ 또는 화면 클릭 후 마우스 좌우 이동 : 시점 회전
  • Enter : 약통의 색을 몸에 채우기 (약통은 비워짐)
  • Space : 화살 쏘기 (주운 뒤 무제한)
  • F : 검 사용 - 발밑 반경 3 범위의 적 제거 (주운 뒤 무제한)
  • Q : 마법봉 사용 - 살아있는 모든 졸라맨을 형광 보라색 감옥에 가둠, 먼지가 닿아야 풀려남 (주운 뒤 무제한)
  • E : 망치 사용 - 가까운 먼지를 부수고, 가까운 벽을 부숴 새 길을 냄 (주운 뒤 무제한)
  • 엘리베이터 근처에서 숫자키 1~21 입력 : 그 층으로 이동 (두 자리는 십의자리·일의자리를 짧게 같이 누르기, 예: '1'+'2' → 12층)
  • ㅎ(G) : 긴급 정지 아이템 (게임당 1회, 20초간 졸라맨들이 멈춤)
